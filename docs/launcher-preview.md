# frun 个人启动器预览版

## 唤醒与位置

- 默认长按鼠标中键 **400 毫秒**呼出面板。达到阈值时就显示，松开中键后面板保留，再用左键点击软件；松开中键不会启动软件。
- 面板搜索框出现在触发时的鼠标附近，固定软件排列在下方。屏幕边缘自动向工作区内调整，支持负坐标副屏和 DPI 缩放。
- 键盘快捷键仍使用外观设置中的原有位置。默认 Alt+Space，可在“设置 → 唤醒”中修改。
- “设置 → 唤醒”有 **200～1000 毫秒**的长按滑块，50 毫秒一步，松开滑块生效。
- 短按中键会补发原始点击；达到阈值前移动超过 8 个屏幕像素会交还中键拖拽。长按唤醒时不再触发浏览器自动滚动。
- 短按补发使用系统输入接口，受 Windows 的权限和应用输入方式限制。管理员窗口、使用特殊输入方式的软件应在本机验证，或加入排除名单，让中键完整直通。

## 暂停和应用排除

- 设置的“暂停唤醒”和托盘右键的“暂停唤醒／恢复唤醒”统一控制中键与全局键盘快捷键。
- 手动暂停期间，中键不拦截，全局快捷键解除注册。托盘和设置仍可使用。手动暂停只在当前运行期间有效，退出重开后恢复正常。
- “设置 → 唤醒”可以选择 exe 文件，或从正在运行的应用窗口中选择，加入排除名单。名单按 exe 名精确匹配，忽略大小写，右侧 × 或键盘 Delete 可删除。
- 当前**前台应用**在名单里时自动暂停；切回桌面或其他应用后自动恢复，游戏留在后台不影响唤醒。
- 手动暂停优先级最高，切换应用不会解除手动暂停。暂停期间托盘显示暂停图标，悬停说明手动暂停或当前命中的程序名。
- 设置列表支持滚轮滚动和键盘上下移动，较长名单不会被窗口高度截断。

## 固定软件和搜索

- 搜索软件后，右键 → 固定到首页，或 Ctrl+P 固定／取消固定选中软件。
- 清空输入后按固定顺序显示四列图标；有输入时使用原有搜索和路径补全。
- 固定软件较多时，用翻页按钮、滚轮或 PageUp/PageDown 翻页；方向键移动，Enter 启动。
- 固定目标、顺序、长按时长和应用排除名单会保存，重启后保留。暂时不在索引中的固定目标保留在配置里，重新索引到它后恢复显示。

## 已启动软件

- 默认开启“设置 → 常规 → 优先唤醒已有窗口”。找到对应的可见主窗口时切换到它，最小化窗口先恢复；多个窗口优先选择最近使用的窗口。
- 普通桌面程序按完整 exe 路径匹配，打包应用尝试按应用标识匹配。只在后台或托盘运行、没有可用主窗口时，继续调用软件原来的启动入口。
- 带参数的快捷方式（例如指定文件、网址或工作区）保留原有动作。管理员启动也保留原有语义。
- 右键“新开实例”可跳过 frun 的窗口复用，是否真正新开由软件本身决定。
- Windows 拒绝前台切换时提示并闪烁目标任务栏按钮，不会因此额外启动一份进程。

## 使用预览版

从最新 Actions 构建的 Artifacts 下载 `frun-middle-mouse-pins-windows`，解压后退出正在运行的 frun（托盘右键 → 退出），再运行新的 frun.exe。若 Quicker 仍占用中键，请先关闭它的中键唤醒或退出 Quicker。

本版本与原版共用配置、缓存和单实例标识；更新来源为 elias-chen/frun。构建产物未代码签名。

## Windows 实机验收

1. 分别测试短按、400ms 长按、长按后松开、长按前拖动；在屏幕四角、不同缩放的副屏上检查位置与点击。
2. 把实际游戏 exe 加入名单，前台时验证中键和原快捷键均交还游戏，Alt+Tab 切出后恢复；再验证手动暂停不会因切换应用而解除。
3. 测试托盘暂停／恢复和图标提示；暂停后重启恢复正常；名单和长按时长应保留。
4. 在普通窗口、最小化窗口、多窗口浏览器、托盘软件、带参数快捷方式中验证切换与启动；“新开实例”和管理员启动仍可用。
5. 固定多个软件、翻页、搜索、拼音、路径补全和长名单滚动均应保持正常。
