# 中键与固定软件预览版

- 单击鼠标中键显示或收起面板；原有 Alt+Space 和自定义键盘快捷键仍可用。
- 设置 → 常规可以关闭中键呼出。启用时中键原有操作（浏览器自动滚动、中键打开链接、CAD 平移等）会被占用；滚轮滚动和左右键不受影响。
- 输入软件名称，右键结果 → 固定到首页；也可用 Ctrl+P 固定或取消固定选中软件。
- 清空搜索框后，固定的软件以四列图标显示，顺序为固定的先后顺序；有输入时继续使用原有搜索与路径补全。
- 固定软件较多时用面板右上角的翻页按钮、鼠标滚轮或 PageUp/PageDown 翻页；方向键移动，Enter 启动。
- 固定记录和中键开关保存在现有 config.toml 中，重启后保留。暂时不在索引中的目标保留在配置里，但不显示；重新索引到它后恢复。
- 当前未固定任何软件时，首页继续显示原有的常用软件列表。从搜索结果固定第一个软件后即可看到图标面板。
- 自动更新来源已改为 elias-chen/frun，避免原作者后续发布的版本替换本改造版。

下载 Actions 构建产物中的 zip，解压后退出正在运行的 frun（托盘右键 → 退出），再运行本目录的 frun.exe。若 Quicker 同时占用中键，请先关闭 Quicker 的中键唤醒或退出 Quicker。

此版本与原版共用配置、缓存和单实例标识。它不包含 Quicker 的 OCR、脚本动作等功能。Windows 上的中键拦截、焦点切换、多显示器/DPI 和真实程序启动仍应按下面的清单验收。

## 手工验收

1. 中键呼出，搜索软件并启动；再次中键收起。关闭中键开关后，浏览器中键打开链接应恢复，键盘呼出仍应正常。
2. 搜索并固定多个软件，清空输入检查图标，退出后重开确认固定顺序保留；右键或 Ctrl+P 取消固定。
3. 固定超过一页的软件，检查按钮、滚轮、PageUp/PageDown，确认末页软件可访问；切换显示器和缩放后检查窗口没有超出工作区。
4. 输入中文、拼音和路径，检查原有搜索、Tab 补全、管理员启动、右键菜单与 Esc 行为。
