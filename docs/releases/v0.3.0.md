## frun 0.3.0

本分支首个正式发布版，基于 [Nongfsq/frun](https://github.com/Nongfsq/frun) 0.2.1，增加适合鼠标操作的日常软件启动流程，无需会员订阅。

### 新增

- **长按中键 → 松开 → 左键选择软件**。默认 400 ms，设置 → 唤醒中可调整为 200～1000 ms，步长 50 ms。
- **跟随鼠标位置呼出**，搜索框靠近触发点，自动处理屏幕边缘、负坐标副屏与 DPI 缩放。
- **固定软件首页**，四列图标、分页、右键或 Ctrl+P 固定；输入继续搜索、拼音匹配与路径补全。
- **手动暂停／恢复**，设置和托盘统一控制。暂停时中键直通，全局快捷键解除注册；手动暂停仅对本次运行有效。
- **前台应用排除**，可选 exe 文件或正在运行的窗口加入名单。游戏等应用在前台时自动暂停，切出恢复，名单持久保存。
- **优先唤醒已有窗口**，恢复最小化窗口，多窗口优先最近使用；右键“新开实例”可跳过复用。
- 自动更新检查本分支，避免原仓库更新覆盖改造功能。

### 下载与升级

- 推荐下载 **frun-v0.3.0-windows-x64.zip**，解压后运行 frun.exe，支持 Windows 10 / 11 x64。
- **frun.exe** 为单文件版本，**frun.exe.sha256** 为自动更新所需校验文件；ZIP 另附校验文件与许可证。
- 替换前先从托盘退出旧版。与原版共用配置和缓存，可先备份 `%APPDATA%\frun`。
- 若 Quicker 同时占用中键，请先关闭其对应唤醒方式。原版用户首次切换需要手动下载。

### 使用边界

- 短按中键通过系统输入接口补发；管理员应用或特殊输入软件可加入禁用名单，使中键直通。
- 没有可用主窗口时使用软件原来的启动入口。带参数快捷方式和管理员启动保留原语义。
- Windows 拒绝切换前台窗口时提示并闪烁任务栏，不会因此额外启动进程。
- “新开实例”跳过 frun 的复用逻辑，最终是否新开由目标软件决定。

构建流程在 Windows 上执行检查、测试和 release 构建，并回读校验发布资产。游戏、管理员应用、特殊输入和不同显示器组合仍需在实际使用环境验证。详细说明：[使用指南](https://github.com/elias-chen/frun/blob/v0.3.0/docs/usage.md)。
